- **Column semantics (deliberately independent):**
  - **Acceptance** — is this requirement currently wanted? Values: **Accepted** (stated in a requirement-bearing document and not contradicted) · **Assumed** (long-implemented, never formally stated) · **Unknown** (source stale or contradicted; current intent unclear) · **Proposed** (inferred from code/tests; needs an adoption decision). *An old requirement's current acceptance may be Unknown. Current behavior is documented, not thereby approved: Proposed rows describe what the code does without implying anyone accepted it as a requirement.*
  - **Implementation** — what the code at the audited revision does, with evidence labels: [confirmed] observed in source · [test] asserted by an in-tree test (not executed unless stated) · [executed] run during the 2026-09-19 audit · [inferred] · [unresolved].
  - **Verification** — what evidence exists that the implementation meets the statement. Separate from acceptance and from implementation.
